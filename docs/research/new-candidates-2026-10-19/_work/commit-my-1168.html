fix(jobs): return float averages from timestamp diff macros on PostgreSQL
EXTRACT(EPOCH ...) and AVG return numeric on PostgreSQL, which Postgrex decodes to Decimal, so round(avg_duration * 1000) in get_job_stats/1 raised ArithmeticError and the Jobs page failed to mount. Cast to float8 in both timestamp diff macros so SQLite and PostgreSQL return floats.
