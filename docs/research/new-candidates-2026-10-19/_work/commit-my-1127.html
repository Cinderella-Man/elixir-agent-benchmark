fix(watch-sync): list fully when copies were mapped since the last run
A copy mapped after its watch was listed counted as not found, and its LastPlayedDate predates every later cursor, so incremental runs never returned it again. Re-marking it watched in Jellyfin was the only way to surface it. Any mapping inserted since the user's last finished, successful run now forces one full listing. Refs #1097
