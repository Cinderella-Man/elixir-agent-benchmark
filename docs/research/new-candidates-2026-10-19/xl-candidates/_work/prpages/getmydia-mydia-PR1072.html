What

Every file on a movie or episode detail page now has a stream link, the way Stash does it. Click it and the browser or OS hands the URL to whatever app plays video. Copy it from the file details modal and paste it into VLC, mpv or Infuse.

  • A link icon on each file row (movies and episodes), shown whether or not the player is enabled.
  • A Stream Link block in the file details modal with a Copy button. It uses the Clipboard API on HTTPS and falls back to a prompt on plain-HTTP LAN installs.

How

  • GET /stream/<token>/<basename> serves the raw file with Range support. There is no transcoding: the external player handles codecs.
  • The token is a Phoenix.Token over {user_id, media_file_id}. Links never expire. Every request reloads the user and the file, skips trashed files and re-checks library restrictions, so deleting the user, restricting them or trashing the file stops the link at once. Rotating secret_key_base revokes every link.
  • Every failure is the same bare 404. Responses carry cache-control: private, no-store.
  • The route has no session, no ENABLE_PLAYER gate and no remote-access check. It is a web UI feature, separate from the player's API.
  • Hrefs are relative, so they resolve to whatever host the browser used, including behind a reverse proxy.
  • The 200/206/416 response code moved out of StreamController into RangeHelper.send_file_ranged/2, which both controllers now use. StreamController keeps its direct-play session tracking.

Testing

  • Controller tests: 200, 206, HEAD, filename ignored, tampered token, trashed file, deleted user, restricted user, file missing on disk, player disabled, no-store header.
  • LiveView tests: the movie row link, the episode row link and the modal link each resolve to the right user and file.
  • The route crawl test now covers /stream/:token/:filename.
  • Full suite run locally.

Not yet checked by hand: opening a link in a real player.

Summary by CodeRabbit

  • New Features
    • Added secure links for streaming media files, with access checked each time a link is opened.
    • Added controls to open and copy stream links from file details and episode rows.
    • Video streams support byte-range requests for partial playback and return an error for invalid range requests.
