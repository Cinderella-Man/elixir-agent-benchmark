This is a WIP PR which tackles the remaining work for adding dynamic repos support. I didn't include tests, specs, function docs, and @doc since tags, because I'd like to first verify if you're ok with this approach from the technical point of view.

I hacked a quick experiment on the project where this is supposed to be used, and it worked properly. Assuming that no significant API changes are requested in this PR, I'd first like to try this branch properly in our branch, to see if everything makes sense. If I see no significant issues, I'll proceed to finish this PR.

Most of the work in this PR revolves around wrapping repo operations. I introduced Oban.Repo module which wraps all repo functions currently used in Oban, except for Ecto.Repo.load, because that one doesn't require setting prefix or dynamic repo instance pid.

This module is intended to be a part of the public API, because it has to be used by plugins (otherwise they will access the wrong instance, or more likely fail b/c they will try to use the global instance which does not exist).

With those changes in place, adding the support for dynamic repos was straightforward, as can be seen in the last commit.
